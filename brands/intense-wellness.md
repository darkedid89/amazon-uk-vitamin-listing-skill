## 4. Compliance restrictions

### Forbidden combos (zero tolerance, brand-level)

- `weight loss guarantee` / `guaranteed weight loss` / `lose [N] kg`
- `clinically proven` (без RCT — у нас нет proprietary clinical trials)
- `cure` / `treat` / `prevent` / `heal` + любое health term
- `cures diabetes` / `prevents obesity` / любая disease-treatment связка
- `melatonin` / `CBD` / `yohimbe` (UK POM/novel food/banned)
- `best` / `#1` / `most effective` / `superior to` (ASA comparative)
- `FDA approved` (false in UK)
- `Made in UK` (если manufacturing CN/EU — не подтверждено)
- `25mcg of [vitamin]` mismatch с label (must match label verbatim)
- `for diabetics` / `for type 2 diabetes` (medical condition targeting)

### Brand-level amber list (use sparingly, MEDIUM-tier counter)

- `weight loss` (без guarantee — OK как category descriptor для keto)
- `fat burn` / `fat burner`
- `appetite control` / `appetite suppressant`
- `metabolism boost` / `metabolism support`
- `slimming`
- `detox`
- `keto diet` (better: `keto lifestyle`, softer)
