## 4. Compliance restrictions

### Forbidden combos (zero tolerance)

- `cure` / `treats` / `prevents` + any menopause symptom
- `HRT alternative` (drug-comparison risk)
- `Viagra alternative` (irrelevant but always flagged)
- `clinically proven` (without trial data)
- `prescription strength` / `Rx-grade`
- `endorses` / `recommended by [doctor name]` (unless verifiable)
- Words: `cure`, `eliminate`, `stops [symptom]`, `permanent relief`, `guaranteed`
- "Adaptogen" descriptor for ashwagandha (not authorised UK)
- "Nootropic" descriptor (not authorised UK)
- "Phytoestrogens" health claim (descriptive only)

### Mandatory certifications в каждом листинге

- [x] **Vegan** (per launch plan — verify Vegan Society cert)
- [x] **Sugar-Free** (KILLER positioning vs Novomins which contains glucose syrup)
- [x] **Gluten-Free**
- [x] **Made in UK** (verify with manufacturer before claim)
- [x] **GMP** (only if facility certified)

### Mandatory disclaimers

- [x] 3 базовые UK warnings
- [x] **Pregnancy/breastfeeding advisory** (critical for menopause demographic)

## 12. Notes

- **Compliance flagged in teardown:**
  - STARPOWA uses "expertly formulated" — vague but acceptable
  - Health & Her uses "expertly developed" — acceptable
  - Issviva uses "Boosts Mood, Energy & Focus" — `boosts` is RISKY (yellow flag), replace with "contributes to" / "supports"
  - Directpurity uses "achieving hormone harmony and easing menopause symptoms" — `easing menopause symptoms` is YELLOW FLAG (implies medical relief), use "support during menopause" instead

- **Saffron Affron® claim:** Pharmactive Biotech publishes RCTs supporting mood claims, but UK NHC Register does NOT authorise saffron-specific claims. Build mood positioning through Vitamin B6 NHC claim, not saffron.

- **KSM-66® Ashwagandha:** Ixoreal Biomed publishes RCTs supporting stress/sleep/testosterone outcomes, but UK NHC for ashwagandha is "on hold". Describe as ingredient + dose only. Build claims through Vitamin B6/B12/Magnesium if in formula.

- **Critical "Made in UK" verification:** confirm with manufacturer before label print. Most UK competitors (Health & Her, Novomins, Wellwoman, Vitabiotics) use UK manufacturers — if Vitgem manufactures abroad, switch to "Produced for [FBO]".
