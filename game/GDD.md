# 🥤 COLA SNATCH — «Отними последнюю»
### Game Design Document · v2.0 · Pitch-ready (investor / publisher / dev team)

> **Логлайн (за 3 секунды):** «Одна банка Coca-Cola на всех. Схвати её, пей — и не дай отнять».
>
> **Формат:** Hyper-Casual Arena · top-down · 15–30 сек/раунд · одна рука · «один против мира».
> **Движок:** Unity (URP). **Команда:** 3–5 человек. **MVP:** 8–10 недель.
> **Играбельный прототип:** `game/index.html` (HTML5/Canvas) — полный вертикальный срез core-механики.

---

## 0. Краткое резюме для инвестора (TL;DR)

| Параметр | Значение |
|---|---|
| Жанр | Hyper-Casual Arena / keep-away (`.io`-вайб) |
| Бизнес-модель | Реклама (rewarded + interstitial) + косметика + Battle Pass. **Zero Pay-to-Win.** |
| Платформы | iOS 13+ / Android 8+ (портрет, 9:16) |
| Целевое CPI | $0.10–$0.25 (Tier-1) |
| Прогноз retention | D1 45–50% · D7 14–18% · D30 4–6% |
| Виральный крюк | «Один против мира»: толпа охотится за носителем; перехват банки на 99% |
| Бренд | Партнёрство с реальным брендом (Coca-Cola) + fallback-бренд |
| Оценка коммерческого успеха | **7.5 / 10** (см. §15) |

Почему это работает по 5 осям: **простота** (беги к банке, держи её), **вовлечённость** (постоянная смена лидера, перехваты, power-ups), **монетизация** (rewarded «второй рывок», Battle Pass, косметика бегунов), **вирусность** (драма перехвата на последней секунде), **простота разработки** (нет нетворкинга — «мультиплеер» имитируют боты; нет сложной физики тел).

## 1.2. Выводы

- Жанр перегружен **runner'ами** — поэтому уходим в **top-down арену** (ТЗ запрещает Subway/Temple/Fruit Ninja).
- **«Один против мира»** доказан (Crowd City), но обычно это пассивный рост толпы. **Активная борьба за единственный предмет** с механикой кражи — свежее и драматичнее.
- **Тема газировки** свободна на уровне сильной меты. Бренд-партнёрство даёт UA-рычаг.
- **Окно инноваций:** соединить (а) «горячую картошку» (keep-away), (б) тайминговый dash-перехват, (в) satisfying «глоток» Coca-Cola как условие победы.

# ШАГ 2. ПЯТЬ КОНЦЕПЦИЙ

> Core Loop · уникальная механика · сложность (1–5) · виральность · ретеншен.

### Концепция A — «Cola Snatch» ⭐ (победитель)
- **Core Loop:** все бегут к банке → схватил → пьёшь (шкала глотков) → толпа гонится → тебя выбивают рывком → ты гонишься и перехватываешь → первый до 100% побеждает.
- **Уникальная механика:** **SNATCH & SIP** — удержание банки копит «глотки», но носитель медленнее и подсвечен; **DASH-перехват** отнимает банку по таймингу.
- **Сложность:** 3/5 · **Виральность:** 5/5 · **Ретеншен:** 4/5.

### Концепция B — «Cola Rush» (вертикальная гонка)
- **Core Loop:** спринт вверх к банке, гонка с ботами. **Механика:** hold-to-sprint + risk «перегрев».
- **Сложность:** 2/5 · **Виральность:** 4/5 · **Ретеншен:** 3/5. (Прежний прототип; менее динамичен моментально.)

### Концепция C — «Soda Hunt»
- Поиск спрятанной банки по «следу пузырьков». **Сложность:** 3/5 · **Вир.:** 3/5 · **Рет.:** 3/5. Сессии длиннее 30 сек.

### Концепция D — «Pop Master» (ASMR-открывашка)
- Тайминг открытия банки. **Сложность:** 2/5 · **Вир.:** 4/5 · **Рет.:** 2/5. Мало глубины.

### Концепция E — «Cola Merge»
- Мерж банок + гонка очков. **Сложность:** 3/5 · **Вир.:** 2/5 · **Рет.:** 4/5. Близко к Suika-клонам.

## 2.1. Матрица выбора

# ШАГ 3. УНИКАЛЬНАЯ МЕХАНИКА — «SNATCH & SIP»

### Суть
Top-down арена. На ней **одна банка Coca-Cola**. Управление — одним пальцем (аналоговый «плавающий джойстик») + кнопка **РЫВОК (Dash)**.

```
СВОБОДНАЯ БАНКА → коснулся первым → СТАЛ НОСИТЕЛЕМ
НОСИТЕЛЬ        → пьёт (растёт шкала «глотков»), НО медленнее и подсвечен
ПОГОНЯ          → соперники бегут к носителю
DASH в носителя → ПЕРЕХВАТ: банка переходит к атакующему, носителя отбрасывает
ПОБЕДА          → первый, кто набрал 100% глотков
```

### Ключевой risk-reward
- Держать банку = копить победу, **но** ты медленнее и ты — мишень для всех.
- Перехват возможен **только рывком** (по кулдауну) — это окно навыка: тайминг важнее спама.
- Прогресс «глотков» **не сгорает** при потере банки → постоянная смена лидера, «качели», драма до последней секунды.

### Power-ups (динамические качели)
| Иконка | Эффект |
|---|---|
| ⚡ Разгон | временный буст скорости/ускорения носителю |
| ❄ Стоп | заморозка всех соперников на ~1.6 сек |
| 🥤 Глоток | мгновенно +18% к шкале (камбэк-инструмент) |

### Почему уникальна
1. **Verb не из рынка:** не бег (runner), не резка (slasher), не стек/мерж. Это **«удержи и отними»** — keep-away за дефицитный предмет.
2. **Тема и механика — одно целое:** победа = выпить колу; защита = убежать с ней; атака = выбить рывком.
3. **Понятно без обучения:** «беги к банке, держи её» — нулевой онбординг.
4. **Эффект «ещё раунд»:** swingy-исход за 15–30 сек, проигрыш злит (соперник пьёт *твою* колу) → мгновенный реванш.

### Похожие решения и отличия
| Существующее | Что общего | Чем отличаемся |
|---|---|---|
| Crowd City | «один против мира» | активная борьба за **1 предмет**, а не рост толпы |
| Hole.io / Paper.io | динамика лидера | лидерство через **удержание банки**, не территорию |
| Aquapark.io | толкание | толкание возведено в **core dash-перехват** |
| Hot-potato/tag | keep-away | добавлены **накопление победы, power-ups, мета, бренд** |

> **Вывод:** «Brawl-lite keep-away за банку Coca-Cola» — комбинация не занята в hyper-casual и патентно-безопасна.

# ШАГ 4. ПОЛНЫЙ GDD

## 4.1. GAME OVERVIEW
| Поле | Значение |
|---|---|
| **Название** | COLA SNATCH — «Отними последнюю» |
| **Жанр** | Hyper-Casual Arena keep-away (top-down) |
| **Платформы** | iOS 13+, Android 8+ (портрет 9:16) |
| **Целевая аудитория** | 13–45, оба пола; ядро 16–30, TikTok/Reels-аудитория |
| **USP** | «Одна Coca-Cola, все против тебя. Удержи и допей — или выбей рывком». Единственный keep-away за банку колы. |

## 4.2. CORE GAMEPLAY
### Игровой цикл (схема)
```
   ┌───────────────────────────────────────────────────────────┐
   │  3-2-1-GO!                                                 │
   │      ▼                                                     │
   │  СВОБОДНАЯ БАНКА ── коснись первым ──► ТЫ НОСИТЕЛЬ          │
   │      ▲                                     │               │
   │      │                                     ▼               │
   │   соперник                            ПЕЙ (шкала+) и БЕГИ  │
   │   выбил рывком ◄──── DASH ──── толпа гонится за тобой      │
   │      │                                     │               │
   │      └──► ТЫ ГОНИШЬСЯ и ПЕРЕХВАТЫВАЕШЬ ◄────┘               │
   │      ▼                                                     │
   │  100% ГЛОТКОВ ── ПОБЕДА: GULP 🥤 ──► [ДАЛЬШЕ]              │
   │  соперник 100% ── ОБОШЛИ ──► [ЗАНОВО / реванш]             │
   └───────────────────────────────────────────────────────────┘
            ▲                                       │
            └────────────── «ещё раунд» ◄───────────┘
```
### Управление
- **Палец** в любом месте экрана — аналоговый бег (плавающий джойстик). **Кнопка РЫВОК** (низ-право) — dash. Десктоп: WASD/стрелки + Space.

### Правила победы / поражения
- **Победа:** твоя шкала глотков достигает 100%.
- **Поражение:** шкала любого соперника достигает 100% раньше. Не death-loop: мгновенный рестарт + rewarded «второй рывок».

## 4.3. LEVEL DESIGN
- **Арена** в портретном экране, стены-отскоки, **препятствия** (ледяные ящики) для навигации/блоков.
- **Прогрессия:** соперников 3→7, скорость/агрессия ИИ ↑, препятствий больше, целевые глотки те же (раунд остаётся 15–30 сек).
- **Генерация:** позиции препятствий и спавны power-ups — процедурные, с проверкой дистанций (без застреваний).

| Параметр | Формула (прототип) |
|---|---|
| Кол-во соперников | `clamp(3+⌊(lvl-1)/2⌋, 3, 7)` |
| Скорость соперника | `224 + lvl*4 + i*2` |
| Агрессия ИИ | `clamp(0.55 + lvl*0.05, …, 1.0)` |
| Препятствия | `clamp(2+⌊lvl/2⌋, 2, 7)` |

## 4.4. META SYSTEMS
- **Прокачка (косметическая):** стили бегунов/трейлы рывка/эффекты глотка. Не влияет на статы (no P2W).
- **Коллекционирование:** **«Runner Locker»** — 60+ скинов бегунов и банок (страны, ретро, праздники, бренд-коллабы).
- **Достижения:** «5 побед подряд», «3 перехвата за раунд», «победа без потери банки», «камбэк с 0%».
- **Ежедневные задания:** 3/день (напр.: «выиграй 3 раунда», «сделай 10 перехватов», «подбери 5 power-ups»).

## 4.5. ECONOMY
| Валюта | Источник | Трата |
|---|---|---|
| 🫧 Bubbles (soft) | раунды, дейлики, дубликаты | скины, рероллы |
| 🎟️ Caps (premium) | Battle Pass, достижения, IAP | премиум-косметика |
| ⭐ Pass XP | раунды, дейлики, события | прогресс Battle Pass |
**Баланс:** ~1 косметический анлок каждые 30–40 минут F2P; никакая валюта не влияет на скорость/силу.

## 4.6. MONETIZATION (реклама / косметика / battle pass — без P2W)
| Канал | Реализация | Почему не P2W |
|---|---|---|
| Rewarded — «Второй рывок» | при поражении: реклама → мгновенный готовый dash на реванш-секунду | шанс на навык, не покупная сила |
| Rewarded — «×2 Bubbles» | удвоение soft-валюты | косметический фарм |
| Interstitial | каждые 3–4 раунда (remote-config) | стандарт HC |
| Косметика (IAP) | скины бегунов/банок/арен, эффекты | визуал |
| Battle Pass (4 недели) | Free+Premium, ~50 наград | косметика + валюта на косметику |

## 4.7. RETENTION
| Метрика | Цель | Как достигаем |
|---|---|---|
| **D1** | 45–50% | мгновенный fun, «ещё раунд», первый скин рано, дейлики |
| **D7** | 14–18% | Battle Pass, Runner Locker, недельные челленджи, лиги |
| **D30** | 4–6% | сезоны, бренд-коллабы, турниры, лидерборды друзей |

Хуки: near-miss перехват (реванш), смена лидера (азарт), коллекция (собирательство), Pass+дейлики (ежедневный заход).

## 4.8. LIVE OPS
- **Сезонные события (4 нед.):** «Summer Fizz Fest», «Retro Cola 80s», «Winter Frost» — тематические арены/скины/ивент-валюта.
- **Турниры (еженедельно):** лиги Bronze→Diamond по рейтингу; async-«призраки» реальных игроков как соперники.
- **Челленджи:** «Steal Master» (макс перехватов), «No-Drop» (победа без потери банки), «Comeback» (камбэк с малого %).
- **Бренд-коллабы:** лимитированные банки/арены реального партнёра к промо-кампаниям.

## 4.9. ART DIRECTION
- **Стиль:** яркий стилизованный 3D-мульт (URP, toon-shading), глянцевая Coca-Cola, читаемые top-down силуэты бегунов.
- **Палитра:** кола-ред `#E10916` + fizz-gold `#FFD23F` + foam `#FFF4E0` на тёмно-вишнёвом `#220A0A`. Высокий контраст для сторовых превью.
- **UI:** капсулы-пилюли HUD, динамический промпт сверху (ХВАТАЙ/ПЕЙ И БЕГИ/ОТБЕРИ), шкала глотков с маркером лидера, круглая кнопка РЫВОК с кулдаун-кольцом.
- **VFX:** сияние банки, кольцо-прогресс на носителе, брызги/пузырьки, вспышка и шейк на перехвате, конфетти и «GULP!» на победе, иней на заморозке.
- **Анимации:** беговой цикл (ножки-точки), отдача при столкновениях, увеличение носителя, финальный глоток.

## 4.10. AUDIO
- **Музыка:** энергичный поп-фанк, нарастание в финале раунда; победный стинг.
- **Звуки:** «хват» банки, «бульк» глотка, низкий «steal» с шумом на перехвате, dash-свист, тики отсчёта 3-2-1, фанфары/«облом».
- **Обратная связь:** каждое событие озвучено + haptic (лёгкий — глоток/подбор, средний — толчок, сильный — перехват/победа).

## 4.11. TECHNICAL
| Поле | Решение |
|---|---|
| **Движок** | **Unity 2022 LTS + URP** (HC-pipeline, медиация, remote-config, быстрые билды) |
| **Почему не Unreal** | избыточен для HC: размер билда, скорость итерации, ad-экосистема |
| **Команда** | 4 чел.: геймдиз/продюсер, Unity-программист, 3D/VFX-артист, UI/маркетинг-артист (+0.5 QA/аналитик) |
| **Стек** | LevelPlay/AppLovin MAX, Firebase/GameAnalytics, Remote Config, PlayFab/Nakama (Pass/лиги) |
| **Сроки MVP** | **8–10 недель** (core + 20 уровней + база меты + реклама) |
| **Релиз** | Soft-launch 14–16 нед., глобал ~22–26 нед. после метрик |

> Прототип `game/index.html` реализует: арену, аналоговое управление + dash, банку (хват/перехват/глотки), 3–7 ботов с ИИ, препятствия, power-ups, отсчёт, win/lose-секвенции, сохранение прогресса.

# ШАГ 6. ТАБЛИЦА РИСКОВ
