# 🥤 COLA RUSH: LAST CAN STANDING
### Game Design Document · v1.0 · Pitch-ready (investor / publisher / dev team)

> **Логлайн (объясняется за 3 секунды):** «Последняя банка газировки — одна на всех. Доберись до неё первым и осуши до дна».
>
> **Формат:** Hyper-Casual · вертикаль · 15–30 сек/уровень · одна рука · «один против мира».
> **Движок:** Unity (URP). **Команда:** 3–5 человек. **MVP:** 8–10 недель.

---

## 0. Краткое резюме для инвестора (TL;DR)

| Параметр | Значение |
|---|---|
| Жанр | Hyper-Casual Arcade Race (vertical) |
| Бизнес-модель | Реклама (rewarded + interstitial) + косметика + Battle Pass. **Zero Pay-to-Win.** |
| Платформы | iOS 13+ / Android 8+ (портрет) |
| Целевое CPI | $0.10–$0.25 (Tier-1), стиль «satisfying + competition» |
| Прогноз retention | D1 45–50% · D7 14–18% · D30 4–6% |
| Виральный крюк | «Один против мира» — гонка 6 банок за последнюю; перехват на финише |
| Бренд | Партнёрство с реальным брендом (Coca-Cola/Pepsi) + fallback «FIZZ» |
| Оценка коммерческого успеха | **7.5 / 10** (см. §15) |

Почему это работает по всем 5 осям: **простота** (1 действие — держать палец), **вовлечённость** (гонка с живой шкалой места), **монетизация** (rewarded на финише = «допить и обогнать»), **вирусность** (перехват банки на последней секунде = идеальный TikTok-клип), **простота разработки** (нет физики тел, нет нетворкинга, фейк-мультиплеер ботами).

## 1.2. Выводы по рынку

- **Рынок hyper-casual насыщен runner'ами и slasher'ами** — поэтому ТЗ прямо запрещает Fruit Ninja / Subway / Temple Run. Свободная ниша: **вертикальная «всплывающая» гонка с risk-управлением**.
- **«Один против мира» (Crowd City, Join Clash) доказал виральность**, но почти всегда реализован как горизонтальный runner. **Перенос в вертикаль + тема напитка = свежесть.**
- **Тема газировки почти не занята** на уровне сильной меты — есть только one-trick флип-игры. Бренд-партнёрство даёт огромный UA-буст и доверие.
- **Окно инноваций:** соединить (а) satisfying-сенсорику открытия/глотка колы, (б) соревнование за дефицитный ресурс, (в) risk-механику «не перегрей банку».

# ШАГ 2. ПЯТЬ КОНЦЕПЦИЙ

> Для каждой: Core Loop · уникальная механика · сложность реализации (1–5) · виральность · прогноз ретеншена.

### Концепция A — «Cola Rush: Last Can» ⭐ (победитель)
- **Core Loop:** старт → газуешь вверх по шахте автомата → уклоняешься от льда, собираешь пузырьки → обгоняешь 5 банок-соперников → хватаешь последнюю банку → **глоток** → следующий уровень.
- **Уникальная механика:** **FIZZ CONTROL** — держишь палец = копится газ (carbonation) и растёт скорость, но **перегрев = банку «срывает» (стан)**. Управление ритмом «держи-отпусти».
- **Сложность:** 2/5 (нет физики тел, нет нетворкинга).
- **Виральность:** 5/5 (перехват на финише — готовый клип «one vs world»).
- **Ретеншен:** 4/5 (шкала места + «ещё уровень» + косметика банок).

### Концепция B — «Fizz Tower»
- **Core Loop:** строишь башню из банок вверх на время.
- **Механика:** тайминг-тап для ровной кладки.
- **Сложность:** 2/5 · **Виральность:** 3/5 · **Ретеншен:** 2/5. Слишком one-trick.

### Концепция C — «Soda Hunt» (поиск-детектив)
- **Core Loop:** ищешь спрятанную банку по «следу пузырьков» (горячо/холодно) в мини-локации.
- **Механика:** плотность пузырьков = близость банки.
- **Сложность:** 3/5 · **Виральность:** 3/5 · **Ретеншен:** 3/5. Сессии длиннее 30 сек — против ТЗ.

### Концепция D — «Pop Master» (ASMR-открывашка)
- **Core Loop:** идеальный тайминг открытия банки без потери пены.
- **Механика:** свайп-открытие + удержание давления.
- **Сложность:** 2/5 · **Виральность:** 4/5 (ASMR) · **Ретеншен:** 2/5. Мало геймплейной глубины.

### Концепция E — «Cola Merge Race»
- **Core Loop:** мерж банок + гонка по очкам.
- **Механика:** merge + соревнование.
- **Сложность:** 3/5 · **Виральность:** 2/5 · **Ретеншен:** 4/5. Близко к Suika — риск «ещё один клон».

# ШАГ 3. УНИКАЛЬНАЯ МЕХАНИКА — «FIZZ CONTROL»

### Суть
Игрок управляет **газированной банкой**, которая всплывает вверх по шахте торгового автомата на «гейзере пены». Единственный input:

```
ПАЛЕЦ ЗАЖАТ  → банка газует вверх (быстро), КОПИТСЯ carbonation-метр
ПАЛЕЦ ОТПУЩЕН → банка идёт на крейсере (медленно), газ стравливается
ВЕДЁШЬ ВБОК   → банка смещается влево/вправо (уклонение/сбор)
```

**Ключевой твист (risk-reward):** carbonation-метр имеет «зелёную зону» (0.4–0.8) максимальной тяги и **красную зону**. Если передержать → **PoP!** — банку «срывает давлением», стан 0.85 сек, ты теряешь место в гонке. Нужно газовать **ритмично**, а не зажимать постоянно.

### Почему она уникальна
1. **Verb не из рынка:** не бег (runner), не резка (slasher), не стек/мерж. Это **«управление давлением всплытия»** — прямое отражение физики газировки.
2. **Тема и механика — одно целое:** «газ» в банке буквально и есть управление. Игрок понимает связь без слов.
3. **Понятно без обучения:** держать = вверх; это интуиция уровня Flappy/Helix, но с **позитивным риском** (перегрев), который читается визуально (банка краснеет, дрожит, кольцо-предупреждение).
4. **Эффект «ещё один уровень»:** гонка заканчивается за 15–30 сек победой/перехватом — мгновенный исход + кнопка «Дальше». Шкала места справа держит напряжение до последней секунды.

### Похожие решения и отличия

| Существующее | Что общего | Чем мы отличаемся |
|---|---|---|
| Flappy Bird (tap-to-rise) | удержание = высота | у нас **risk-метр** (перегрев), гонка с соперниками, нет «мгновенной смерти» |
| Helix Jump / Stack Ball | вертикаль | у нас **всплытие вверх + соревнование**, а не падение |
| Crowd City / Join Clash | «один против мира» | у нас **вертикаль + risk-механика**, не толпа/runner |
| Aquapark.io | гонка-вайб | у нас **управление давлением**, а не физический слайд |
| Bottle Flip / Soda-flip | тема напитка | у нас **глубокий core + мета + LiveOps**, а не one-trick |

> **Вывод:** FIZZ CONTROL — это «Flappy встречает Crowd City в вертикальной банке колы». Комбинация не занята на рынке и патентно-безопасна (механика давления + гонка ботов).

# ШАГ 4. ПОЛНЫЙ GDD

## 4.1. GAME OVERVIEW

| Поле | Значение |
|---|---|
| **Название** | COLA RUSH: Last Can Standing |
| **Жанр** | Hyper-Casual Arcade Race (vertical, single-input) |
| **Платформы** | iOS 13+, Android 8+ (портрет, 9:16) |
| **Целевая аудитория** | 13–45, оба пола; ядро 16–30, casual-мобайл, TikTok/Reels-аудитория |
| **USP** | «Гонка за последней банкой газировки. Газуй, но не перегрей — иначе тебя перехватят на финише». Единственная вертикальная risk-гонка с темой колы. |

## 4.2. CORE GAMEPLAY

### Игровой цикл (схема)
```
   ┌──────────────────────────────────────────────────────────┐
   │  ЗАПУСК УРОВНЯ                                            │
   │      │                                                    │
   │      ▼                                                    │
   │  ГАЗ ВВЕРХ  ◄── держи палец (риск: перегрев → PoP)        │
   │      │                                                    │
   │      ├──► УКЛОНЯЙСЯ ОТ ЛЬДА (стан при ударе)              │
   │      ├──► СОБИРАЙ ПУЗЫРЬКИ (буст скорости + очки)         │
   │      ├──► СЛЕДИ ЗА ШКАЛОЙ МЕСТА (ты vs 5 соперников)      │
   │      ▼                                                    │
   │  ФИНИШ: «ПОСЛЕДНЯЯ БАНКА»                                 │
   │      ├──► ПЕРВЫЙ → 🥤 ГЛОТОК + конфетти → [ДАЛЬШЕ]        │
   │      └──► НЕ ПЕРВЫЙ → перехват → [ЗАНОВО / rewarded-shot] │
   └──────────────────────────────────────────────────────────┘
            ▲                                          │
            └──────────── «ещё один уровень» ◄─────────┘
```

### Управление
- **Одна рука, один палец.** Зажатие = газ. Положение пальца по X = смещение банки. Десктоп-фоллбэк: `Space`/`↑` газ, `←/→` смещение.

### Правила победы
- Достичь отметки «последней банки» (distance = `goal`) **раньше всех 5 соперников** → анимация глотка → уровень пройден.

### Правила поражения
- Любой соперник достигает `goal` раньше игрока → «Перехватили!». **Не death-loop:** мгновенный рестарт + опция rewarded-ad «Финишный рывок» (см. монетизацию).

## 4.3. LEVEL DESIGN

### Структура уровней
- Уровень = вертикальная шахта длиной `goal = 2600 + level*420` юнитов.
- Контент процедурный: лёд-препятствия (часть качается по синусоиде), кластеры пузырьков на «физ-линии» (подсказка оптимального пути).

### Прогрессия сложности
| Параметр | Формула | Эффект |
|---|---|---|
| Длина трассы | `2600 + level*420` | дольше = выше напряжение |
| Скорость соперников | `base*[0.86..1.04] + level*[2..6]` | боты умнеют |
| Плотность препятствий | `×(1 + level*0.12)` | теснее коридор |
| Базовая скорость мира | `170 + level*7` | общий темп |

Кривая: уровни 1–5 — онбординг (рост уверенности), 6–15 — «настоящая» гонка, 16+ — мастерство тайминга газа. Каждый 10-й уровень — **«Boss Vending»** (двойная трасса, скин-награда).

### Генерация контента
- Seed-based procedural: один seed на уровень → детерминированно (для фейр-гонки и A/B). Кластеры пузырьков всегда задают «идеальную траекторию», лёд — соблазн срезать.

## 4.4. META SYSTEMS

- **Прокачка (косметическая, НЕ статы):** «Carbonation Style» — визуальные эффекты газа (обычный → радужный → молниевый). На геймплей не влияет (no P2W).
- **Коллекционирование:** **«Cola Vault»** — 60+ скинов банок (страны, ретро-этикетки, праздничные, бренд-коллабы). Дубликаты → soft-валюта.
- **Достижения:** «10 побед подряд», «Финиш с перегревом 0 раз», «100 пузырьков за уровень», «Победа за 18 сек».
- **Ежедневные задания:** 3 в день (напр.: «Выиграй 3 уровня», «Собери 50 пузырьков», «Финишируй без удара о лёд»). Сброс в 00:00 локального времени.

## 4.5. ECONOMY

| Валюта | Источник | Трата |
|---|---|---|
| 🫧 **Bubbles (soft)** | сбор в уровне, дейлики, дубликаты скинов | разблокировка скинов, рероллы заданий |
| 🎟️ **Caps (premium)** | Battle Pass, редкие достижения, IAP-косметика | премиальные скины/эффекты |
| ⭐ **Pass XP** | завершение уровней, дейлики, события | продвижение по Battle Pass |

**Баланс прогрессии:** медиана — 1 косметический анлок каждые ~30–40 минут игры на F2P; премиум-эффекты — только за Caps (Battle Pass/IAP). Никакой валюты не влияет на скорость/тягу — **строго cosmetic**.

## 4.6. MONETIZATION (только реклама / косметика / battle pass — без P2W)

| Канал | Реализация | Почему не P2W |
|---|---|---|
| **Rewarded Ad — «Финишный рывок»** | при перехвате: посмотри рекламу → один буст-рывок на ту же гонку | даёт второй шанс на навык, не покупаемую силу |
| **Rewarded Ad — «Удвоить пузырьки»** | ×2 soft-валюта в конце уровня | косметический фарм |
| **Interstitial** | каждые 3–4 проигрыша/уровня (частота под ремоут-конфиг) | стандарт HC |
| **Косметика (IAP)** | скины банок, эффекты газа, темы шахты | чисто визуал |
| **Battle Pass (сезон 4 недели)** | Free + Premium трек, ~50 уровней наград (скины, эффекты, Caps) | награды косметические + валюта на косметику |

ARPDAU-драйвер: rewarded (объём) + Battle Pass (стабильный доход на ядре).

## 4.7. RETENTION

| Метрика | Цель | Как достигаем |
|---|---|---|
| **D1** | 45–50% | мгновенный fun, «ещё уровень», первый скин на 3-м уровне, дейлики |
| **D7** | 14–18% | Battle Pass-прогресс, коллекция Vault, недельные челленджи, лиги |
| **D30** | 4–6% | сезонные события, бренд-коллабы, турниры, лидерборды друзей |

Хуки удержания: (1) **near-miss перехват** → желание реванша; (2) **видимая шкала места** → азарт; (3) **Vault-коллекция** → собирательство; (4) **дейлики + Pass** → ежедневная причина зайти.

## 4.8. LIVE OPS

- **Сезонные события (4 недели):** «Summer Fizz Fest», «Retro Cola 80s», «Winter Frost Cans» — тематические шахты, эксклюзивные скины, ивент-валюта.
- **Турниры (еженедельно):** лиги по Trueskill-подобному рейтингу (Bronze→Diamond), топ получают премиум-скины. Соперники в гонке могут подставляться как «призраки» реальных игроков (async).
- **Челленджи (ежедневно/выходные):** «Зеро-перегрев Weekend», «Спидран-суббота» (минимальное время), «Pixel-perfect» (без удара о лёд).
- **Бренд-коллабы:** лимитированные банки реального партнёра к промо-кампаниям (Хэллоуин, ЧМ, кинопремьеры).

## 4.9. ART DIRECTION

- **Стиль графики:** яркий стилизованный 3D-мульт (URP, toon-shading, мягкие тени), «аппетитная» глянцевая газировка, крупные читаемые силуэты банок.
- **Цветовая палитра:** доминанта — **кола-ред `#E10916`** + **fizz-gold `#FFD23F`** + foam `#FFF4E0` на тёмно-вишнёвом фоне `#26040A`. Высокий контраст для превью в сторе.
- **UI:** скруглённые «газировочные» капсулы, крупные кнопки (one-thumb), пилюли HUD сверху, вертикальная шкала места справа, carbonation-метр слева.
- **VFX:** пузырьки, брызги пены при бусте, «PoP»-взрыв при перегреве, конфетти и блик на финишной банке, экранный flash.
- **Анимации:** «дыхание» банки (bob), наклон при смещении, глаза-персонаж (charm), сочный «глоток» на победе (squash/stretch + glug).

## 4.10. AUDIO

- **Музыка:** энергичный поп-фанк луп, ускоряется в финальной трети гонки (адаптивный слой), праздничный стинг на победе.
- **Звуки:** шипение газа (boost), «бульк» пузырька, треск льда (удар), «PoP» при перегреве, фанфары + 4 «глотка» на финише.
- **Обратная связь игроку:** каждое действие озвучено + тактильный haptic (лёгкий — пузырёк, средний — удар, сильный — PoP/победа). Реализация WebAudio в прототипе, FMOD/нативка в продакшене.

## 4.11. TECHNICAL

| Поле | Решение |
|---|---|
| **Движок** | **Unity 2022 LTS + URP** (лучший pipeline для HC, Mediation, Remote Config, быстрый билд под iOS/Android) |
| **Почему не Unreal** | Unreal избыточен для HC: размер билда, скорость итерации и экосистема ad-mediation хуже под казуалку |
| **Размер команды** | 4 чел.: 1 геймдиз/продюсер, 1 Unity-программист, 1 3D/VFX-артист, 1 UI/маркетинг-артист (+0.5 QA/аналитик аутсорс) |
| **Стек** | Unity LevelPlay/AppLovin MAX (медиация), Firebase/GameAnalytics, Remote Config (баланс/частота рекламы), бэкенд для Pass/лиг — PlayFab/Nakama |
| **Сроки MVP** | **8–10 недель** (core + 20 уровней + базовая мета + реклама) |
| **Сроки релиза** | **Soft-launch 14–16 нед.** (CA/PH/Tier-2), **глобальный релиз ~22–26 нед.** после метрик |

> Прилагаемый прототип (`game/index.html`) — **играбельный вертикальный срез core-механики** (FIZZ CONTROL + гонка 5 ботов + финиш-глоток + прогрессия) на HTML5/Canvas. Подтверждает feel до старта Unity-продакшена.

# ШАГ 7. ОЦЕНКА КОММЕРЧЕСКОГО УСПЕХА

## 🎯 **7.5 / 10**

### Обоснование по осям

| Ось | Балл | Комментарий |
|---|---|---|
| **Простота** | 9/10 | Один палец, понятно за 5 сек, идеальная HC-сложность входа |
| **Виральность** | 8/10 | «Перехват последней банки» — готовый short-video крюк, «один против мира» доказан |
| **Вовлечённость** | 7/10 | Risk-механика + шкала места держат напряжение; нужно подтвердить D1 плейтестами |
| **Монетизация** | 7/10 | Без P2W потолок ARPU ниже, но Battle Pass + rewarded + косметика дают здоровый mix |
| **Простота разработки** | 9/10 | Нет нетворкинга/физики тел, MVP за 8–10 нед., команда 4 чел. — реалистично |
| **Дифференциация** | 7/10 | Свежая комбинация в насыщенном жанре; риск «ещё одна vs-world игра» |

### Почему 7.5, а не выше
- Hyper-casual — рынок с огромной дисперсией: даже отличный feel требует выигранной UA-лотереи (CPI vs eCPM). Без подтверждённого CPI и D1 ставить 9–10 нечестно.
- Отказ от P2W (по ТЗ) сознательно ограничивает монетизационный потолок ради здоровья продукта и бренд-безопасности — это снижает «денежный» балл, но повышает шанс бренд-партнёрства.

### Почему не ниже 7
- Все требования ТЗ выполнены одновременно; механика **патентно-безопасна и тематически цельная**; бренд-партнёрство даёт редкий UA-рычаг; играбельный прототип снижает product-риск №3.

### Условия «апгрейда до 8.5+»
1. Soft-launch D1 ≥ 48% и CPI ≤ $0.20.
2. Подписанный бренд-партнёр (Coca-Cola/Pepsi) → кратный буст органики и доверия.
3. Виральный клип-формат «перехвата» выстреливает в TikTok/Reels.
